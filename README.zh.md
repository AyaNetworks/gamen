# Gamen (画面)

一个探索**多智能体AI工作流的制品优先设计**的UI模型。Gamen展示了四个核心范式:

1. **制品优先屏幕** — AI输出和制品是一等公民，而非短暂的聊天
2. **自动代理提示更新** — 通过指南动态编辑实现实时代理重新配置
3. **用户主导的工具和任务管理** — 对工具执行和任务编排的明确用户控制
4. **知识库集成** — 统一文档库用于上下文智能

采用React 19、Zustand和Framer Motion构建。受Dione工作空间概念启发。MIT许可证。

---

## 🎯 哲学

### 制品优先屏幕

工作空间将AI输出视为**持久制品**，而非转瞬即逝的消息:

- **思考追踪**: 逐步AI推理与执行细节
- **工具执行日志**: 工具参数、结果、错误追踪和时间戳
- **协作制品**: 带有版本控制和发布功能的Markdown便签
- **上下文知识**: 双源文档库（知识库+用户上传）

每个制品都在工作空间内保持可见且可访问，创建持久上下文。

### 自动代理提示更新

代理不是静态的。**指南编辑器**允许实时代理重新配置:

- 编辑和审查代理系统提示而无需重启
- 即时修改工具可用性和任务参数
- 变更立即应用于进行中的对话
- 指南历史记录用于追踪配置演变

### 用户主导的工具和任务管理

用户在整个AI操作中保持控制:

- **任务集成**: 通过聊天中的@mentions创建、管理和引用任务
- **明确的工具选择**: 配置代理可以访问的工具
- **双向链接**: 任务和对话保持同步
- **任务面板**: 按优先级和状态查看、搜索和筛选任务

用户指导代理行为。代理增强——永不替代——人类判断。

### 知识库集成（库面板）

上下文智能是统一且可访问的:

- **双源文档**: 一个面板中的知识库和用户上传
- **多态预览**: Markdown、PDF、Excel、Word、图像和代码——全部内联呈现
- **丰富元数据**: 类别、框架、级别、来源、上传时间戳
- **拖放**: 立即向聊天或便签添加文档
- **附件连续性**: 文档与消息保持链接以保持上下文

知识从不超出范围——它与工作空间内的对话并存。

指南编辑器在不重启对话的情况下实现动态代理重新配置:

库面板用丰富元数据标记（类别、频道、专业知识级别、来源、时间戳）统一AI知识和用户上传:

任务设置模态框提供全面的任务搜索、按状态和优先级筛选、以及带项目关联的详细任务描述:

![Task Settings & Management](screens/task-settings.png)

工具设置模态框显示按类别（搜索、云存储等）组织的可用工具，带有启用/禁用切换和单个工具配置:

![Tool Settings & Configuration](screens/tool-settings.png)

通过按名称、电子邮件或角色搜索用户来邀请协作者:

![Invite Collaborators](screens/collaborators-adding.png)

![Member Information & Management](screens/collaborators-editing.png)

工作空间支持与团队成员的实时协作、透明的成员管理和基于角色的组织。

## ✨ 功能

### 🗨️ 聊天面板

- **多个聊天会话**，具有持久消息历史记录
- **丰富的消息类型**:
  - **标准响应**（完整Markdown，包含语法突出显示）
  - **思考追踪**（逐步推理，包含执行详细信息）
  - **工具执行日志**（参数、结果、错误追踪，带时间戳）
  - **系统消息**（协作事件和状态更新）
- **交互式详细信息模态框** — 检查推理、工具参数和错误日志
- **任务@mentions** — 通过聊天内联引用任务，带自动完成
- **文件附件** — 预览图像、文档和媒体
- **回复线程** — 引用和参考特定消息
- **主题切换** — 在动画暗和亮主题之间切换

### 📝 便签（制品编辑器）

- **多标签Markdown编辑器**，带完整编辑/预览模式
- **每标签撤销/重做历史记录**，带视觉导航
- **发布系统** — 发布带参与追踪的笔记（视图、点赞、分享）
- **实时统计** — 带动画转换的实时字符和字数
- **下载导出** — 本地保存Markdown内容
- **文档集成** — 拖入文档到便签进行注释
- **完整Markdown支持** — 表格、列表、代码块、语法突出显示

### 📚 文档库（知识面板）

- **双源文档管理**:
  - 知识库文档（AI参考）
  - 用户上传文件（PDF、Excel、Word、图像、代码、文本、Markdown）
- **格式支持**:
  - **Markdown**: 原生呈现，包含语法突出显示
  - **PDF**: 内联iframe预览
  - **Excel**: HTML表格转换
  - **Word**: 通过Mammoth进行HTML呈现
  - **图像、代码、文本**: 直接呈现，带适当样式
- **元数据标记** — 类别、框架、级别、来源、上传时间
- **文件操作** — 拖放上传、下载、删除
- **预览模态框** — 全屏文档查看

### ⚙️ 指南编辑器（代理配置）

- 编辑代理系统提示和指令
- 配置任务模板和参数
- 管理工具可用性和设置
- 变更立即应用于进行中的对话

### 🎨 主题和UI

- **动画主题**:
  - **深色**: 具有发光重点和闪烁星星的夜空
  - **浅色**: 漂浮云朵的白天天空
- **可调整大小的多面板布局** — 专业面板控制，带流畅过渡
- **Framer Motion动画** — 基于弹簧的模态框打开、计数器动画、图标编排
- **自定义样式** — 磨砂玻璃效果、自定义滚动条、主题感知组件
- **响应式设计** — 适应不同屏幕尺寸

## 💡 设计哲学

Gamen是**一个探索多代理AI工作流UX范式的工作原型**——不是生产应用。它提出了这些问题:

- **如果制品是一等公民呢?** 不被埋藏在聊天历史中，而是持久且可访问。
- **如果代理可以动态重新配置呢?** 不在部署时固定，而是可通过指南编辑适应。
- **如果用户有明确控制呢?** 不在代理自主性背后隐藏，而是通过任务和工具管理可见。
- **如果知识总是可访问呢?** 不分散在工具中，而是在工作空间中统一。

这些是设计问题，而非最终答案。Gamen展示了一种可能的人类-AI协作方式。
