# Gamen (画面)

**다중 에이전트 AI 워크플로우를 위한 아티팩트 우선 설계**를 탐색하는 UI 목업입니다. Gamen은 4가지 핵심 패러다임을 입증합니다:

1. **아티팩트 우선 화면** — AI 출력과 아티팩트는 일시적인 채팅이 아닌 일등 시민
2. **자동 에이전트 프롬프트 갱신** — 실시간 에이전트 재설정을 위한 동적 지침 편집
3. **사용자 주도 도구 및 작업 관리** — 도구 실행 및 작업 조율에 대한 명시적 사용자 제어
4. **지식 기반 통합** — 문맥 지능을 위한 통합 문서 라이브러리

React 19, Zustand 및 Framer Motion으로 구축됨. Dione 워크스페이스 개념에 영감받음. MIT 라이선스.

## 🎯 철학

### 아티팩트 우선 화면

워크스페이스는 AI 출력을 일시적인 메시지가 아닌 **지속적인 아티팩트**로 처리합니다:

- **사고 추적**: 단계별 AI 추론 및 실행 세부사항
- **도구 실행 로그**: 도구 인수, 결과, 오류 추적 및 타임스탬프
- **협업 아티팩트**: 버전 관리 및 발행 기능이 있는 Markdown 스크래치패드
- **상황별 지식**: 이중 출처 문서 라이브러리 (지식 기반 + 사용자 업로드)

모든 아티팩트는 워크스페이스 내에서 보이고 접근 가능하여 지속적인 컨텍스트를 만듭니다.

### 자동 에이전트 프롬프트 갱신

에이전트는 정적이지 않습니다. **지침 편집기**는 실시간 에이전트 재설정을 가능하게 합니다:

- 재시작 없이 에이전트 시스템 프롬프트 편집 및 검토
- 도구 가용성 및 작업 매개변수를 즉시 수정
- 변경사항은 진행 중인 대화에 즉시 적용
- 구성 진화를 추적하기 위한 지침 이력

### 사용자 주도 도구 및 작업 관리

사용자는 AI 작업 전반에 걸쳐 제어를 유지합니다:

- **작업 통합**: 채팅의 @mentions를 통해 작업 생성, 관리 및 참조
- **명시적 도구 선택**: 에이전트가 접근할 수 있는 도구 구성
- **양방향 링크**: 작업과 대화는 동기화 상태 유지
- **작업 패널**: 우선순위와 상태별로 작업 보기, 검색 및 필터링

사용자는 에이전트 동작을 가이드합니다. 에이전트는 인간의 판단을 보강하지만 결코 대체하지 않습니다.

### 지식 기반 통합 (라이브러리 패널)

상황별 지능은 통합되고 접근 가능합니다:

- **이중 출처 문서**: 한 패널의 지식 기반 및 사용자 업로드
- **다형 미리보기**: Markdown, PDF, Excel, Word, 이미지 및 코드—모두 인라인으로 렌더링됨
- **풍부한 메타데이터**: 카테고리, 프레임워크, 레벨, 출처, 업로드 타임스탬프
- **드래그 앤 드롭**: 즉시 채팅 또는 스크래치패드에 문서 추가
- **첨부파일 연속성**: 문서는 컨텍스트를 위해 메시지와 연결 유지

지식은 절대 손이 닿지 않는 곳에 있지 않습니다—워크스페이스의 대화 옆에 존재합니다.

## 🎬 시각적 개요

### 3 패널 워크스페이스 아키텍처

통합 워크스페이스는 채팅, 아티팩트 및 지식을 한 조정된 환경에 통합합니다:

**다크 모드** — 빛나는 기술 악센트가 있는 밤하늘
![Gamen Dark Mode](screens/darkmode-default-screen.png)

**라이트 모드** — 표류하는 구름이 있는 낮 하늘
![Gamen Light Mode](screens/lightmode-default-screen.png)

### 아티팩트 우선 스크래치패드

모든 스크래치패드 아티팩트는 버전 관리, 라이브 통계 (문자/단어 수, 참여 지표) 및 빠른 작업을 위한 원형 아티팩트 컨트롤러를 갖추고 있습니다:

![Artifact Controller](screens/artifact-controler.png)

발행된 아티팩트는 각 스크래치패드 하단의 실시간 애니메이션 통계로 참여도를 추적합니다.

### 자동 에이전트 프롬프트 갱신

지침 편집기는 대화를 재시작하지 않고 동적 에이전트 재설정을 가능하게 합니다:

![Guideline Editor](screens/editing-guidelines-by-chat.png)

사용자는 시스템 프롬프트, 작업 매개변수 및 지침을 편집합니다. 변경사항은 진행 중인 대화에 즉시 적용되어 실시간 에이전트 동작 적응을 가능하게 합니다.

### 지식 기반 통합

라이브러리 패널은 풍부한 메타데이터 태깅 (카테고리, 채널, 전문 지식 수준, 출처, 타임스탬프)으로 AI 지식 및 사용자 업로드를 통합합니다:

![Library Panel with Metadata](screens/knowledge-base-item-hovered.png)

문서는 드래그 앤 드롭으로 채팅 또는 스크래치패드에 쉽게 접근 가능하여 상황별 지능을 항상 손에 닿는 곳에 유지합니다.

### 프로젝트 조직 및 채팅 이력

채팅 사이드바는 프로젝트와 조직화된 대화를 표시하여 사용자가 관련 채팅을 그룹화하고 대화 컨텍스트를 유지할 수 있게 합니다:

![Chat History with Project Folders](screens/chat-hostory-and-project-folder-revealed.png)

### 사용자 주도 작업 관리

작업 설정 모달은 포괄적인 작업 검색, 상태 및 우선순위별 필터링, 프로젝트 관련 세부 작업 설명을 제공합니다:

![Task Settings & Management](screens/task-settings.png)

사용자는 워크스페이스 내에서 직접 작업을 검색, 필터링, 완료 표시, 편집 또는 삭제할 수 있습니다.

### 명시적 도구 구성

도구 설정 모달은 카테고리별로 조직된 사용 가능한 도구 (검색, 클라우드 스토리지 등)를 활성화/비활성화 토글 및 개별 도구 구성과 함께 표시합니다:

![Tool Settings & Configuration](screens/tool-settings.png)

사용자는 에이전트가 접근할 수 있는 도구를 명시적으로 선택하여 기능에 대한 완전한 제어를 유지합니다.

### 협업 워크스페이스

이름, 이메일 또는 역할로 사용자를 검색하여 협력자를 초대합니다:

![Invite Collaborators](screens/collaborators-adding.png)

이메일, 역할 및 멤버십 제어를 포함한 세부사항으로 팀원을 보고 관리합니다:

![Member Information & Management](screens/collaborators-editing.png)

워크스페이스는 팀원과의 실시간 협업, 투명한 멤버 관리 및 역할 기반 조직을 지원합니다.

## ✨ 기능

### 🗨️ 채팅 패널

- **다중 채팅 세션**, 지속적인 메시지 이력
- **풍부한 메시지 유형**:
  - **표준 응답** (완전한 Markdown 및 구문 강조)
  - **사고 추적** (단계별 추론 및 실행 세부사항)
  - **도구 실행 로그** (인수, 결과, 오류 추적 및 타임스탐프)
  - **시스템 메시지** (협업 이벤트 및 상태 업데이트)
- **대화형 세부사항 모달** — 추론, 도구 인수 및 오류 로그 검사
- **작업 @mentions** — 자동 완성으로 인라인 작업 참조
- **파일 첨부파일** — 이미지, 문서 및 미디어 미리보기
- **답글 스레드** — 특정 메시지 인용 및 참조
- **테마 토글** — 애니메이션된 어두운 테마와 밝은 테마 간 전환

### 📝 스크래치패드 (아티팩트 편집기)

- **다중 탭 Markdown 편집기**, 완전한 편집/미리보기 모드
- **탭당 실행 취소/다시 실행 이력**, 시각적 네비게이션
- **발행 시스템** — 참여 추적이 있는 메모 발행 (조회, 좋아요, 공유)
- **라이브 통계** — 애니메이션 전환이 있는 실시간 문자 및 단어 수
- **다운로드 내보내기** — 로컬에 Markdown 콘텐츠 저장
- **문서 통합** — 스크래치패드로 문서 드래그하여 주석 처리
- **완전한 Markdown 지원** — 테이블, 목록, 코드 블록, 구문 강조

### 📚 문서 라이브러리 (지식 패널)

- **이중 출처 문서 관리**:
  - 지식 기반 문서 (AI 참조)
  - 사용자 업로드 파일 (PDF, Excel, Word, 이미지, 코드, 텍스트, Markdown)
- **형식 지원**:
  - **Markdown**: 구문 강조가 있는 기본 렌더링
  - **PDF**: 인라인 iframe 미리보기
  - **Excel**: HTML 테이블 변환
  - **Word**: Mammoth를 통한 HTML 렌더링
  - **이미지, 코드, 텍스트**: 적절한 스타일로 직접 렌더링
- **메타데이터 태깅** — 카테고리, 프레임워크, 레벨, 출처, 업로드 시간
- **파일 작업** — 드래그 앤 드롭으로 업로드, 다운로드, 삭제
- **미리보기 모달** — 전체 화면 문서 보기

### ⚙️ 지침 편집기 (에이전트 구성)

- 에이전트 시스템 프롬프트 및 지침 편집
- 작업 템플릿 및 매개변수 구성
- 도구 가용성 및 설정 관리
- 변경사항은 진행 중인 대화에 즉시 적용

### 🎨 테마 및 UI

- **애니메이션된 테마**:
  - **어두움**: 빛나는 악센트와 반짝이는 별이 있는 밤하늘
  - **밝음**: 표류하는 구름이 있는 낮 하늘
- **조정 가능한 다중 패널 레이아웃** — 부드러운 전환이 있는 전문 패널 제어
- **Framer Motion 애니메이션** — 스프링 기반 모달 열기, 카운터 애니메이션, 아이콘 안무
- **사용자 정의 스타일링** — 유리 프로스트 효과, 사용자 정의 스크롤바, 테마 인식 컴포넌트
- **반응형 설계** — 다양한 화면 크기에 적응

## 💡 설계 철학

Gamen은 **다중 에이전트 AI 워크플로우를 위한 UX 패러다임을 탐색하는 작업 프로토타입**이지 프로덕션 애플리케이션이 아닙니다. 이러한 질문을 제시합니다:

- **아티팩트가 일등 시민이라면?** 채팅 이력에 묻히지 않고 지속적이고 접근 가능합니다.
- **에이전트가 동적으로 재설정 가능하다면?** 배포 시 고정되지 않고 지침 편집을 통해 적응합니다.
- **사용자가 명시적 제어를 한다면?** 에이전트 자율성 뒤에 숨겨지지 않고 작업 및 도구 관리를 통해 보이는 상태입니다.
- **지식이 항상 접근 가능하다면?** 도구에 산재되지 않고 워크스페이스에 통합됩니다.

이것들은 설계 질문이지 최종 답변이 아닙니다. Gamen은 인간-AI 협력의 한 가지 가능한 접근 방식을 입증합니다.
